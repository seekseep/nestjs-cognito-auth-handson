# 進め方

## 1 つのプロジェクトを育てる

このハンズオンでは、02 章で受け取ったプロジェクトに、節ごとに機能を足していきます。リポジトリの `sections/<章>/<節>/` には、**その節を終えた時点のプロジェクト** がそのまま入っています。

```text
sections/
├── 02-starter/
│   └── 01-starter-project/   ← はじめのプロジェクト
├── 03-cognito/
│   └── 02-sign-in/           ← 03 章 02 節を終えた時点
└── ...
```

手元では 1 つのフォルダ（たとえば `~/handson/api/`）を育てていきます。各節のページの手順どおりにファイルを足したり書き換えたりしてください。

## ページの読み方

### コードの差分

ファイルを書き換える手順は、前の節との差分で示します。行頭が `+` の行を足し、`-` の行を消します。新しく作るファイルは、すべての行に `+` が付きます。

```diff lang="ts"
 @Controller('notes')
+@UseGuards(AuthGuard)
 export class NotesController {
```

左の行番号は「書き換える前の行」、右の行番号は「書き換えた後の行」です。

### この節を終えたときのディレクトリ

ページの最後に、その節を終えたときのディレクトリを載せています。前の節から **追加したファイル** と **変更したファイル** には印が付いています。ファイルを選ぶと中身が見られるので、手元のファイルと見比べてください。

その下のボタンから、その節を終えた状態のプロジェクトを ZIP でダウンロードできます。

- 途中の節から始めたいときは、ひとつ前の節の ZIP をダウンロードして展開してください
- 展開したら、`api/` で `npm install` を実行します（`node_modules/` は ZIP に入っていません）
- `api/.env` は ZIP に入っていません。03 章からは、`api/.env.example` をコピーして作り、自分のユーザープール ID とクライアント ID を書いてください

## 前提

- macOS / Windows（PowerShell 7）/ Linux のどれか。Windows に必要なスペックは [道具をそろえる](./01-setup/01-tools/LECTURE.md) の節にあります
- ターミナルの基本的な操作（`cd`・`ls`）ができる
- JavaScript を書いたことがある。TypeScript と NestJS は、読みながら覚えれば大丈夫です
- 03 章から AWS アカウントを使います（Cognito のユーザープールは無料枠の範囲で作れます）
